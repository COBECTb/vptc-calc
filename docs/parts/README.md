# Каталог деталей

`catalog.json` содержит 29 карточек: название, вызов модуля, описание построения
и параметры. `reference_model.scad` — сохранённый результат текущего генератора
для Ø70 (пробелы и отступы нормализованы), `reference_model.encoder.json` — его механические размеры. Отдельные
файлы `rigid_gear.scad`, `cap.scad` и остальные подключают эту модель через `use`
и рисуют одну деталь. Голень и TPU-опора подключают `output/foots.scad`.

## Изменение модели

Из корня проекта создать новый эталон (перезапись здесь намеренная):

```sh
python3 calc-vpts.py --resolution 600 --ratio 19 --roller-d 4 --roller-h 5 \
  --rout 28 --diameter 70 --hole-angle 39 --part encoder_assembly \
  --output docs/parts/reference_model.scad --overwrite
```

Далее сверить значения карточек с новым SCAD и JSON: описания параметров
не вычисляются автоматически. Штатный контур платы V2 встраивается генератором,
поэтому он уже есть в сохранённом SCAD. Ручные изменения `output/vptc_roller.scad`
не являются источником этого эталона.

## Рендер

Требуются OpenSCAD CLI, Python с NumPy и Pillow, clang++. Скрипт экспортирует
каждый модуль в STL через OpenSCAD, затем строит два вида PNG с буфером глубины.
Он не требует графического контекста OpenSCAD. STL-кэш находится в системной
временной папке; в репозитории сохраняются исходники, PNG и `render_manifest.json`.

```sh
python3 docs/parts/render_catalog.py --jobs 3
python3 docs/parts/write_readme_catalog.py
```

Для одной детали: `--only separator`; свой OpenSCAD: `--openscad /path/to/openscad`.
Манифест содержит хеш исходных геометрических файлов, количество треугольников,
габариты и предупреждения CLI. `$fn=60`; число точек профиля жёсткого колеса — 600.
Объёмный вид и вид вдоль Z имеют независимый масштаб, реальные размеры подписаны.
Изображения описывают геометрию; STL-каталог не заменяет проверку печати и сборки.
