# Исходники печатной механики

Эти файлы — входные библиотеки основного `calc-vpts.py`. Самостоятельно открывать
их для сборки не нужно: генератор создаёт комплект с относительными ссылками,
параметрами и переключателем детали. Ручные модели и STL из `output/` не читаются.

| Исходник | Назначение |
|---|---|
| `foots.scad`, `foots_h.scad` | Текущая стопа, зажим и TPU-накладка |
| `clamp_v2.scad` | Две одинаковые половины зажима и два одинаковых магнитных полукольца Ø70 |
| `reducer_v2.scad` | Принятая крышка V2, накладка, карманы, проводка, соединители и сборка |
| `knee_v2.scad` | Принятое колено: карман PCB, крышка заподлицо, полукольцо на двух опорах, кинематика |
| `pcb_v2.scad` | Механическое отображение платы; контур и компоненты добавляет Python из данных KiCad |
| `sensors_v2.scad` | Габариты датчиков, положение чувствительных точек и крепежа |

`mechanical_package.py` собирает библиотеки, диспетчер вариантов, печатные задания,
перечень деталей и экспорт STL. Геометрия базового редуктора и робота остаётся
в `calc-vpts.py`; размерные формулы энкодера — в `encoder_scad.py`.

Принятые установки V2 применяются только к штатному Ø70 с фазой основных
отверстий 39°. Для других размеров остаются параметрические варианты редуктора;
готовую плату и колено генератор не масштабирует. Механические данные платы
берутся из `electronics/encoder_can_v2/design/`; их связь с сохранённой PCB
проверяется хешем, чтобы не получить карманы от устаревшей разводки.

Менять нужно эти исходники и затем повторно запускать генератор. Правки
в созданных `*_assets` будут потеряны при намеренной перегенерации с `--overwrite`.
Для сравнения сохранены прежние модели в `output/`; они не являются зависимостями
нового комплекта. Исходное пересечение тяги с плечом шарнира на 0,5 мм не исправлено.
