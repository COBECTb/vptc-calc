# vptc-calc
Калькулятор ВПТК (Волновой редуктор с роликами)

## Сохранённая плата энкодера

Текущая электрическая плата **CAN V2.4 / D70** находится в [electronics/encoder_can_v2](electronics/encoder_can_v2/README.md). Это фиксированный вариант под конкретную геометрию редуктора Ø70 мм, подшипник 40×52×7 мм и фазу сборочных отверстий 39°. Она имеет четыре слоя и толщину 0,8 мм; варианты другой толщины или с двумя слоями не входят в эту ревизию. Размерная привязка и параметры эталонной сборки — [MECHANICAL_VARIANT.md](electronics/encoder_can_v2/MECHANICAL_VARIANT.md).

## Запуск

Основной `calc-vpts.py` создаёт **полный комплект CAD**: сборки, отдельные
печатные детали, библиотеки геометрии и список деталей. Для текущего Ø70:

```sh
python3 calc-vpts.py --resolution 600 --ratio 19 --roller-d 4 --roller-h 5 \
  --rout 28 --diameter 70 --part knee_assembly \
  --output output/generated/robot.scad
```

Требуется Python с `numpy`. Результат:

- `robot.scad` — общий файл; `generated_part` выбирает сборку или деталь;
- `robot_assets/` — все необходимые библиотеки, включая текущую стопу;
- `robot_print/` — **37 отдельных заданий** с названиями деталей;
- `robot_print/README.md` — количество на узел, материалы и порядок сборки;
- `robot.encoder.json` — размеры, совместимость PCB, перечень деталей и хеши файлов.

Все эти файлы генерируются одним запуском. `--part` выбирает начальное отображение,
а не ограничивает состав комплекта. Папки `robot_assets` и `robot_print` должны
переноситься вместе с `robot.scad`; сохранённых STL или моделей из `output` для
работы генератора не требуется. При повторной генерации нужен `--overwrite`;
защищён каждый файл комплекта, включая библиотеки и отдельные задания печати.

Чтобы сразу получить STL всех печатных вариантов, добавить `--export-stl` к команде.
Нужен установленный OpenSCAD; путь можно передать через `--openscad`. Для отдельных
STL добавить, например, `--export-stl --stl-part encoder_magnet_ring_half --stl-part knee_magnet_ring`.
Файлы появятся рядом с соответствующими SCAD. Исходные варианты и запасные детали
включены в каталог отдельно: печатать весь каталог как комплект одной ноги не нужно.
Количество указано **на узел**, а не на всю собаку; `assemblies` в JSON группирует
детали по назначению.

Автоматический экспорт использует двоичный STL и проверяет замкнутость сетки
и направление граней. Численные вырождения экспорта устраняются с округлением
не более 0,00001 мм; если сетка остаётся незамкнутой, экспорт завершается ошибкой.
Подробности рендера и проверки сохраняются в `*_print/.build/`.

Для правок использовать `calc-vpts.py`, `encoder_scad.py` и исходники в
[`cad/`](cad/README.md), затем повторять генерацию. В `cad/` перенесены принятые
модели редуктора V2, колена с двумя опорами полукольца и текущей стопы.
Для штатного Ø70 плата загружается из сохранённых механических данных KiCad V2;
хеш исходной PCB проверяется перед генерацией. Для другого диаметра рассчитывается
механический вариант редуктора; готовая PCB V2 и колено автоматически не масштабируются.

В исходной механике остаётся осевое пересечение ушка тяги и короткого плеча
шарнира на 0,5 мм. Генератор его сохраняет; это нужно исправить до сборки.
Перенос моделей в генератор не является подтверждением прочности или точности энкодера.

Альтернатива — Docker (с OpenSCAD для экспорта STL):

```
docker build -t vptc-calculator .
```

```
docker run --rm -it \
  -v "$(pwd)":/app -w /app \
  vptc-calculator
```

## Описание

Калькулятор генерирует 3D-модель волнового редуктора с роликами (VPTC - Variable Pace Traction Coupling) с параметрами, задаваемыми пользователем. В папку output помещается файл vptc_roller.scad который необходимо открыть в программе OpenSCAD.

Существующие файлы защищены от перезаписи. Для нового результата укажите `--output`,
а для намеренной перезаписи выбранного файла — `--overwrite`.

### Варианты деталей редуктора для установки энкодера

Для установки абсолютного энкодера предусмотрены доработанные варианты
крышки редуктора, зажима соединителей и обоих соединителей, а также защитная
накладка крышки. Плата и носитель магнитов входят в эту сборку как компоненты
энкодера. Исходные модули деталей и режим `legacy` сохранены. Пример без
интерактивного ввода:

```sh
python calc-vpts.py --resolution 600 --ratio 19 --roller-d 4 --roller-h 5 \
  --rout 28 --diameter 70 --part encoder_assembly \
  --output output/encoder_reducer_generated.scad
```

Рядом сохраняется `*.encoder.json`: размеры колец, положение датчиков/крепежа,
контур платы и осевые размеры для будущей генерации платы. Ни один файл ручных
вариантов в `output` генератор не читает и не изменяет.

Доступные значения `--part`:

| Значение | Результат |
| --- | --- |
| `legacy` | Исходная сборка и модули робота |
| `encoder_assembly`, `encoder_section`, `encoder_exploded` | Сборка, разрез, разнесённая сборка |
| `encoder_cap`, `encoder_lid`, `encoder_print` | Крышка редуктора под энкодер, её защитная накладка, обе детали для печати |
| `encoder_clamp`, `encoder_clamp_half` | Доработанный зажим соединителей под энкодер, одна печатная половина |
| `encoder_magnet_ring`, `encoder_clamp_print` | Отдельные половинки кольца со сквозными отверстиями, две половины стоя и обе половинки кольца плашмя |
| `encoder_connector`, `encoder_load_connector` | Выходной соединитель и соединитель нагрузки редуктора, доработанные под энкодер |
| `encoder_pcb` | Механический контур платы |
| `reducer_complete` | Полный редуктор с крышкой V2, сепаратором, подшипниками и соединителями |
| `leg_assembly` | Нога с текущим коленом V2 и стопой; анимация в пределах проверенного хода колена |
| `knee_assembly`, `knee_section`, `knee_exploded` | Сборка колена, разрез и разнесённый вид |
| `knee_mount`, `knee_stage` | Две опоры полукольца и этапы сборки колена |
| `knee_hip`, `knee_lower`, `knee_shin`, `knee_cover`, `knee_magnet_ring` | Печатные детали колена с платой V2 |
| `encoder_magnet_ring_half` | Одна одинаковая половинка кольца редуктора для печати плашмя |
| `foot_rigid`, `foot_sole`, `foot_cuff` | Текущая стопа с зажимом, TPU-накладка и запасной зажим |
| `body_front`, `body_rear`, `body_battery` | Отдельные секции корпуса робота |

В OpenSCAD выбор можно менять переменной `generated_part`. Все варианты редуктора Ø70
по умолчанию используют угол основных отверстий **39°**, чтобы совпасть с текущей
KiCad-платой и взаимно соответствовать в одном комплекте. Явный `--hole-angle` задаёт
свой угол; генератор предупреждает, если готовая плата Ø70 ему не соответствует.

Колено: `animate=false` включает ручное управление `knee_angle`; при `animate=true`
работает OpenSCAD **Вид → Анимировать**. При `$t=0` отображается заданный угол.
Печатные задания не двигаются при анимации. `legacy` сохраняет прежнюю компоновку
робота, заменяя зависимости от внешних STL процедурными модулями; новые колено
и полная нога представлены отдельными режимами.

Количество магнитов выбирается как максимальная чётная пара при перемычке не менее
0,6 мм между посадками Ø5,2. Внутреннее кольцо содержит на одну пару полюсов меньше:
для Ø70 получается **24/26**, для Ø80 — **30/32**. Радиусы, длина шейки и осевой подъём
вычисляются из размеров: в текущем Ø70 сепаратор и подшипник подняты на 0,5 мм,
шейка соединителя имеет длину **6,75 мм**.
Магнитные посадки вынесены в отдельное кольцо толщиной **0,8 мм** со
сквозными отверстиями Ø5,2, которое печатается двумя одинаковыми половинками
плашмя — по одной на каждую половину зажима. Плоский торец полузажима снижен
с Z12 до Z11,6; верхняя стенка стала тоньше на 0,4 мм. Кольцо занимает
Z11,6–12,4, поэтому положение магнитов и длины соединителей сохранены.
Печатаются две одинаковые половины корпуса зажима и две одинаковые половинки
кольца. Половинку приклеивают к торцу своей половины зажима; толщину клеевого
слоя нужно учитывать при установке.
Для отдельной печати одной половинки есть
`output/connector_clamp_magnet_ring_half_0p8.scad` (нужно два экземпляра).
В каждой половинке Ø70 — 12 внутренних и 13 наружных отверстий. Пластик одинаковый,
но полярность первого магнита наружного ряда у второй половинки противоположная;
у внутреннего ряда — одинаковая. Чередование N/S сохраняется через оба стыка.
Произвольный общий поворот собранного зажима учитывается привязкой к известному
положению сустава (упор или сборочный шаблон) с сохранением смещения нуля.
После переустановки зажима эту привязку повторяют. Установочные метки либо
однозначный механический упор полезны для повторяемости сборки; они не заменяют
проверку погрешности энкодера. Неправильную полярность отдельных магнитов одной
поправкой нуля исправить нельзя.
Под максимальный корпус MCU 5,1×5,1 мм предусмотрен локальный карман с зазором
0,2 мм по сторонам и 0,15 мм снизу. Для Ø70 дно кармана находится на Z10,25,
выше неизменённого подшипникового упора Z10.

Для штатного Ø70 генератор использует контур, два крепления и компоненты
разведённой компактной платы V2 (`electronics/encoder_can_v2`). Механические данные
читаются из `design/mechanics_v2.json`; хеш проверяется по сохранённой PCB.
Экспорт обновляется `scripts/export_mechanics.py` через Python KiCad.
Актуальная воспроизводимая сборка крышки — режим `encoder_assembly` основного генератора.
Сохранённый прежний файл: `output/reducer_cap_encoder_can.scad`.
Для других диаметров плата в генерируемом SCAD остаётся механическим макетом.
Другой диаметр или расположение отверстий требует новой электрической разводки. Подъём сепаратора ещё требует
проверки его окон роликов и сопряжения с 688ZZ в полной сборке редуктора.
У открытых поверхностей вычитания выступают на 0,01 мм; глухие глубины и упор
подшипника сохранены.

Проверки генератора: `python -m unittest discover -s tests -v`. Если установлен
OpenSCAD, они также проверяют компиляцию всех новых вариантов Ø70/Ø80 и реальную
геометрию упора подшипника, дна потая и локального кармана MCU.
Путь CLI можно задать переменной `OPENSCAD`.

## Генерируемые детали

Иллюстрированный каталог ниже показывает **29 ранее сохранённых деталей**.
Актуальный полный перечень, включая колено V2 и отдельные полукольца, создаётся

### Как получить и открыть отдельную деталь

Для каждой детали есть готовый файл в [docs/parts](docs/parts), который вызывает
ровно один модуль и скрывает остальную сборку. Ссылка «Открыть деталь» дана
в каждой карточке. Открыть этот `.scad` в OpenSCAD, нажать **F5** для просмотра,
**F6** для точного рендера, затем **Файл → Экспорт → STL**. Положение для
печати отдельно задано только там, где вызван модуль с суффиксом `_print`.

Картинки и файлы карточек используют сохранённый
[эталонный результат генератора](docs/parts/reference_model.scad):

```sh
python3 calc-vpts.py --resolution 600 --ratio 19 --roller-d 4 --roller-h 5 \
  --rout 28 --diameter 70 --hole-angle 39 --part encoder_assembly \
  --output output/my_reducer.scad
```

Для собственной версии создать рядом с результатом небольшой файл, например
`output/my_cap.scad`:

```scad
use <my_reducer.scad>
$fn=60;
cap();
```

Вместо `cap();` подставить вызов из нужной карточки. Для текущей стопы и TPU-опоры
использовать задания `foot_rigid.scad` и `foot_sole.scad` из созданного каталога `*_print/`.

### Где изменять параметры

| Уровень | Что менять | Когда пересчитывается |
| --- | --- | --- |
| CLI генератора | `--resolution`, `--ratio`, `--roller-d`, `--roller-h`, `--rout`, `--diameter`, `--hole-angle` | Повторным запуском `calc-vpts.py` с новым `--output` |
| Аргументы модулей | Например, `reducer_connector(h1=8,skirt=true)` или `shin(foot=false)` | Сразу при F5/F6 в файле отдельной детали |
| Переменные SCAD | Толщины, высоты, зазоры и размеры посадок в сгенерированном файле | После изменения самого файла, из которого импортируется модуль |
| Библиотека стопы | Переменные `h_*` в `cad/foots_h.scad` | После повторного запуска генератора |

**Профиль впадин, число роликов, координаты отверстий и часть размеров записываются
Python как готовые числа.** Одной замены `D_out` или `d_roller` в SCAD недостаточно:
для другой передачи или диаметра нужно повторно запустить генератор.
Переменные из файла, подключённого через `use`, не становятся переменными внешнего
файла: менять их нужно в исходном SCAD, а через вызов передавать только его аргументы.
Значения в таблицах ниже относятся к указанному эталону Ø70; это не универсальные
размеры для всех диаметров. Исходный генератор и его формулы — [calc-vpts.py](calc-vpts.py),
параметры доработок редуктора под энкодер — [encoder_scad.py](encoder_scad.py).

### Редуктор

#### 1. Жёсткое колесо / корпус

![Жёсткое колесо / корпус](images/parts/rigid_gear.png)

[Открыть деталь](docs/parts/rigid_gear.scad) · Источник: [reference_model.scad](docs/parts/reference_model.scad).

Вызов для отдельного файла:

```scad
rigid_gear();
```

Как построить: Создать цилиндр корпуса. Выдавить рассчитанный Python профиль впадин и вычесть его сверху. Вырезать отверстия A/B и ступенчатую посадку 6803ZZ.

| Параметр | Значение в эталоне | Что задаёт |
| --- | --- | --- |
| `D_out` | 70 | Наружный диаметр, из --diameter |
| `h_reducer` | 15.5 | Высота корпуса: h_roller + 10.5 |
| `h_cut` | 10 | Глубина профильной полости: h_roller + 5 |
| `--ratio / --resolution` | 19 / 600 | 20 впадин и число точек рассчитанного профиля |
| `motor_radius / motor_angles` | 32 / [54,144,234,324]° | Расположение отверстий B |

#### 2. Корпус с боковым креплением

![Корпус с боковым креплением](images/parts/rigid_gear_with_bracing.png)

Вызов для отдельного файла:

```scad
rigid_gear_with_bracing();
```

Как построить: Взять rigid_gear(). Добавить боковой объём, двумя овальными конусами сформировать выемки, повторно прорезать отверстия B и отверстия бокового крепления.

| Параметр | Значение в эталоне | Что задаёт |
| --- | --- | --- |
| `bracing_offset_y` | 29 | Смещение крепления: D_out/2 − 6 |
| `bracing_offset_z` | 17.5 | Высота оси крепления: D_out/4 |
| `bracing_offset_x` | 2.2 | Значение в сгенерированном SCAD; 2.25 в Python округляется до одного знака |
| `side_long / side_short` | 29.564 / 12.246 | Расстояния между боковыми отверстиями |

#### 3. Сепаратор

```scad
separator();
```

Как построить: Создать цилиндр Rsep_out, вычесть внутреннюю полость Rsep_in. Сделать ступени фланца, посадку 688ZZ, радиальные окна под ролики и восемь крепёжных отверстий.

| `separator_h` | 9 | Основная высота: h_roller + 4 |
| `bearing_inner / bearing_outer` | 40 / 52 | Посадка выбранного 6808-2RS |
| `--ratio / h_roller` | 19 / 5 | Число окон / высота роликов |

#### 5. Эксцентрик

![Эксцентрик](images/parts/eccentric.png)

[Открыть деталь](docs/parts/eccentric.scad) · Источник: [reference_model.scad](docs/parts/reference_model.scad).


| Параметр | Значение в эталоне | Что задаёт |

| `h_flange / h_web` | 3.2 / 3.2 | Толщина полок / перемычки |
| `h_root_angle / h_reverse_drop / h_toe_rise` | −8° / 6 / 26 | Параметры изгиба |
| `h_joint_clearance` | 0.15 | Зазор паза на сторону |

### Сборочные режимы редуктора с энкодером

После генерации можно менять `generated_part` в самой модели либо передавать
`-D 'generated_part="encoder_section"'` через CLI OpenSCAD. В файле с `use` удобнее
вызвать `encoder_selected_part("encoder_section");`.

| Режим `--part` / `generated_part` | Что показать | Какие параметры использовать |
| --- | --- | --- |
| `legacy` | Исходная сборка и модули робота | Комментировать вызовы в секции «Сборка», либо открыть одну из карточек |
| `encoder_assembly` | Сборка доработанных деталей редуктора с энкодером | `encoder_assembly(with_bracing=true,show_electronics=true,show_magnets=true)` |
| `encoder_section` | Разрез сборки | `encoder_assembly(section=true)` |
| `encoder_exploded` | Разнесённая сборка | `encoder_assembly(exploded=true)` |
| `encoder_cap` | Крышка редуктора под установку энкодера | `cap_encoder(with_bracing=true)` |
| `encoder_lid` | Защитная накладка крышки редуктора с переносом к Z=0 | `encoder_selected_part("encoder_lid")` |
| `encoder_print` | Крышка редуктора и её защитная накладка рядом | `encoder_selected_part("encoder_print")` |
| `encoder_clamp` | Доработанный зажим соединителей с носителями магнитов | `connector_clamp_encoder(show_magnets=true)`; магниты — фоновые объекты просмотра |
| `encoder_clamp_half` | Корпус полузажима соединителей под энкодер | `connector_clamp_encoder_body_half()`; для печатной ориентации — `encoder_clamp_body_for_print()` |
| `encoder_magnet_ring` | Две половинки носителя магнитов плашмя | `encoder_magnet_ring_for_print()`; одна — `encoder_magnet_ring_half_for_print()` |
| `encoder_clamp_print` | Корпуса полузажимов и носители в печатном положении | `encoder_selected_part("encoder_clamp_print")` |
| `encoder_connector` | Выходной соединитель редуктора под энкодер | `reducer_connector_encoder()` |
| `encoder_load_connector` | Соединитель нагрузки редуктора под энкодер | `load_connector_encoder()` |
| `encoder_pcb` | Механический контур платы | `encoder_pcb_bare()`; это не электрическая разводка |

Изображения обновляются скриптом [render_catalog.py](docs/parts/render_catalog.py).
Подробности воспроизведения — [docs/parts/README.md](docs/parts/README.md).

## Управление сборкой

Внизу, в секции "Сборка", перечисляются детали, можно их создание раскомментировать и подвигать функцией translate:

```
// === Сборка ===
rigid_gear_with_bracing();  // Корпус с боковым креплением
translate([0, 0, h_reducer+1]) cap_with_bracing();  // Крышка с боковым креплением
translate([0, 0, 0.5]) eccentric_shaft();
translate([0, 0, 14]) rotate([180,0,0]) eccentric();
translate([0, 0, ecc_shaft_h1 + ecc_spacer_h-1]) separator();
translate([0, 0, -mc_total_height-1]) motor_cover(); // кожух снизу
```

## Параметры моделирования

Параметр $fn отвечает за разрешение геометрии модели:
```
// ВПТК редуктор с роликами

$fn = 60;  // Рекомендуемое значение для 3D печати
```

В редакторе OpenSCAD есть кнопки рендеринга и экспорт в STL.

## Параметры, запрашиваемые при запуске

- **Количество точек построения профиля жесткого колеса** (по умолчанию: 600) - влияет на точность профиля
- **Передаточное число** (по умолчанию: 19) - основной параметр передачи
- **Диаметр роликов (мм)** (по умолчанию: 4.0) - диаметр роликов сепаратора
- **Высота роликов (мм)** (по умолчанию: 5.0) - высота роликов сепаратора
- **Внешний радиус впадин жесткого колеса (мм)** (по умолчанию: 28.0) - радиус профиля жесткого колеса
- **Внешний диаметр редуктора (мм)** (по умолчанию: 70.0) - общий диаметр корпуса
