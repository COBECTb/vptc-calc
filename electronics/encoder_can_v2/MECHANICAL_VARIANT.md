# Размерный вариант Encoder CAN V2.4 / D70

Идентификатор сохранённой платы: `encoder_can_v2_4_d70`.
Электрический проект находится в этой папке основного репозитория:
`encoder_can_v2.kicad_pro`, `encoder_can_v2.kicad_pcb`, `encoder_can_v2.kicad_sch`.
Это готовая разводка под конкретную геометрию редуктора ВПТК D70.

| Параметр эталонной сборки | Значение |
|---|---|
| Наружный диаметр редуктора | 70 мм |
| Передаточное отношение в эталонном запуске | 19 |
| Ролик в эталонном запуске | Ø4 × 5 мм |
| Наружный радиус впадин жёсткого колеса `--rout` | 28 мм |
| Подшипник на сепараторе | 6808-2RS, 40 × 52 × 7 мм |
| Крышка исходного редуктора | 11 мм |
| Основные сборочные отверстия | R31,5 мм, фаза 39°, шаг 60° |
| Открытые вырезы платы под доступ M3 | Углы 39° и −21° |
| Радиусы магнитных дорожек Hall | 23,5 и 29,5 мм |
| Ориентация Hall U2/U3 в KiCad | 9°, положения сохранены |
| Контур PCB | Исходный узкий, 826 отрезков; наружный радиус 33,4 мм |
| Габарит PCB в радиально-касательной системе | 16,853 × 42,938 мм |
| Стек платы | Четыре слоя, готовая толщина 0,8 мм |
| Крепление PCB | Два NPTH Ø2,2 мм, M2×5, головка не больше Ø3,8×1,3 мм |
| Программирование | Пять площадок J2 с шагом 2,54 мм |

Координаты U2/U3 в системе KiCad: (123,2666; 95,9099) и
(129,1928; 94,9713) мм. Точные контур, крепления, координаты остальных деталей
и габариты корпусов следует брать из PCB и `design/mechanics_v2.json`,
а не восстанавливать по округлённым числам этой таблицы.

Эталонная генерация механики из корня проекта:

```sh
python3 calc-vpts.py --resolution 600 --ratio 19 --roller-d 4 --roller-h 5 \
  --rout 28 --diameter 70 --hole-angle 39 --part encoder_assembly \
  --output output/generated/encoder_d70.scad
```

Совместимые исходники механики: `cad/reducer_v2.scad`, `cad/pcb_v2.scad`,
`cad/clamp_v2.scad`, `cad/sensors_v2.scad`. Существующая установка в колене
`cad/knee_v2.scad` использует ту же сохранённую плату D70 в своей ориентации.
Генератор параметрический, но эта электрическая разводка автоматически
не масштабируется для другого редуктора, положения отверстий или магнитов.
Даже при том же наружном диаметре нужно сверять полную сборку и осевые зазоры.

Проверенная PCB SHA256:
`43237adbcdb743c33c8f1bdc61387ee4b917825291ee4f41e4ae68c7d174684c`.

Производственные исходники — `fabrication/`; состав и установка — `assembly/`.
Текущий запрос опытной партии: **одна панель из четырёх плат, монтаж только двух,
две платы без компонентов**. Панель, стек, технологический запас и точные компоненты
согласуются с производителем. Запрос расчёта не означает запуск изготовления.

Эта ревизия сохраняет отступ меди перехода до паяемых площадок не менее 0,5 мм,
переходы вне максимальных корпусов и закрытую маску переходов с обеих сторон.
Варианты 1 мм / 1,6 мм или двухслойная разводка в эту ревизию не входят.
Пройдены проверки проекта и номинальной механики; работоспособность, точность,
тепловой режим и электромагнитная совместимость требуют собранного образца.
